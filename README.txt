Wordflow 단어 암기 사이트

index.html을 브라우저에서 열면 바로 사용할 수 있습니다. 설치나 인터넷 연결은 필요하지 않습니다. 학습 완료 기록은 현재 브라우저의 로컬 저장소에 저장됩니다. 시작 화면의 기록 내보내기/가져오기 버튼으로 기록을 JSON 파일로 옮길 수 있습니다. 가져오기는 현재 브라우저 기록을 백업 파일 내용으로 바꿉니다.
